> The bill to regulate artificial intelligence arrived as FINAL_final_v7.docx, and after three hearings its author still believes the PDF button is somewhere in the printer.

A single satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The angle: the AI bill itself is the unconvertible file — it arrives as FINAL_final_v7.docx, and its author, three hearings deep, still believes the PDF button lives inside the printer.

Run it with:

```sh
python3 main.py
```

It validates the sentence (one sentence, at most 320 characters), prints it, and writes it to `/output/entry.txt` for the grader.
